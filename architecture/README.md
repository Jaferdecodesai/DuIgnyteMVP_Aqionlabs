# Architecture source and document formats

The latest editable Word document and PDF are at the repository root:

- [Editable system design](../Aqion-Relay-System-Design.docx)
- [PDF system design](../Aqion-Relay-System-Design.pdf)
- [Read the architecture in GitHub](../ARCHITECTURE.md)

The supplied earlier system design was refreshed around the same twelve technical topics. The current version documents the actual Next.js static export, Worker routing, native SQLite Durable Object, session and CSRF controls, synchronous approval transactions, demo limits, release gates and proposed integration/pilot roadmap.

`current-architecture.png` is the diagram embedded in the Word document. Its geometry and all document text/tables are generated by [`scripts/build-architecture.py`](../scripts/build-architecture.py). To rebuild, install the separate document dependencies and run the builder from the repository root:

```sh
python3 -m pip install -r architecture/requirements.txt
python3 scripts/build-architecture.py
```

Convert the resulting DOCX to PDF with Microsoft Word or LibreOffice, then inspect every rendered page before replacing the public PDF. The application itself does not require Python or document libraries. `scripts/verify-release-artifacts.py` checks the final cross-format links, root/pitch copy equality, document integrity and submission file limits.
